# Session, barre rapide et calendrier

- `/daily` : les icônes ItemsAdder sont réappliquées dans la même actualisation que le compte à rebours. Il n’y a plus d’intervalle volontaire avec des coffres vanilla entre deux rendus. Le test simule cinq secondes consécutives avec des items ItemsAdder ; la version réelle d’ItemsAdder est celle du serveur utilisateur.
- Mode de jeu : le mode courant est enregistré dans les données persistantes du joueur à sa déconnexion. Au retour, il est restauré au tick suivant, même si le réglage vanilla `force-gamemode` a remis la survie pendant le chargement. Les annulations explicites des autres protections sont respectées. Les modes et l’étoile sont conservés par les sauvegardes playerdata habituelles ; aucune migration SQLite.
- `/gm [0|1|2|3] [joueur]` : raccourci réservé à `cliker.gamemode.admin` (opérateur par défaut). Sans argument, bascule survie/créatif. Les mots français et anglais des modes sont aussi reconnus. La console doit préciser un joueur en ligne.
- Étoile Menu ClickHunter : en case 9 de la barre rapide (index Bukkit 8), clic droit pour ouvrir `/menu`. L’objet précédent est déplacé dans une case libre. Si les 36 cases sont pleines, aucun objet n’est écrasé : libérer une case puis fermer un inventaire permet de réessayer automatiquement. Les livraisons `/claim` en cours sont attendues avant l’installation. L’étoile est protégée contre le déplacement, le jet, la main secondaire et la vente AH ; elle est retirée des drops de mort puis restituée après réapparition.
- Gains dans l’ActionBar : Écus jaunes, Gemmes vertes, Cendres violet clair, XP bleu clair ; séparateurs gris. Les réglages `/settings` continuent de permettre de masquer cette ligne.

Validation : 188 tests automatisés réussis, sans échec, erreur ou test ignoré. Essai natif Paper 1.21.4 : étoile présente en neuvième case, ouverture au clic droit dans l’air, vente refusée, créatif conservé après reconnexion avec `force-gamemode=true`, étoile conservée sans doublon. Le fichier `validation/session-interface.json` contient les preuves et le SHA-256 du JAR.
